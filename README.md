The goal of this university project was to put us junior developers through the main phases of creating an app in a professional setting. 
Using the agile software development methods, we had to create a website from scratch that would fulfill the needs of our client and respect the time constraints. 
In groups of 7 or 8, we had to preemptively meet and designate roles to each member, and establish the tools we would use. For 3 days, we organized standup meetings and sprints, and used a backlog as well as Trello to organize the tasks among us. 
Every few hours, we would do demos for the app with the client, and then have a meeting with our designated coach. Our only rules for this project were to include as many features present in the backlog as possible, which our team was able to do entirely.
I was primarily in charge of web programming and web design, but also often lended a hand on the file management and task organization.
